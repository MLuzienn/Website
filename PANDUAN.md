# Panduan Singkat

Buka `index.html` di browser untuk melihat website.

## Yang perlu diganti (cari kata "GANTI" di index.html)
1. **Nama PT**: ganti "PT Mataram Baja Mandiri" (nama contoh) di semua tempat.
2. **Nomor telepon/WhatsApp**: ganti `6281234567890` dan `+62 812-3456-7890`.
3. **Email**: ganti `info@namaperusahaan.co.id`.
4. **Alamat & peta**: ganti alamat, lalu di Google Maps pilih Bagikan > Sematkan peta, dan salin link `src` ke iframe peta.
5. **Logo**: ganti `images/logo.svg` (boleh pakai .png, lalu sesuaikan nama filenya di index.html).
6. **Foto**: ganti file di folder `images/` dengan foto asli Anda. Pakai nama file yang sama, atau sesuaikan di index.html.
7. **Angka, proyek, testimoni, logo klien**: semuanya data contoh, ganti dengan data asli.

## Warna
Warna diatur di bagian atas `style.css` (`--hijau`, `--krem`, dll).

## Publikasi
Upload seluruh folder (index.html, style.css, images/) ke hosting statis apa saja,
misalnya Netlify, GitHub Pages, Cloudflare Pages, atau cPanel hosting.
